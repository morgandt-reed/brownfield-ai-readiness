# Fixture estate

Eight repositories and one unrecognised directory, committed so that every
number and every table in this repository's README can be reproduced by running
the scanner against a tree that is in the repository.

They are not exemplary. They are shaped to exercise the cases that make the
argument: an estate that barely concentrates into archetypes, a repository whose
test command is inferable and whose tests do not exist, one whose versions are
managed by a parent POM so the pinning signal reads low for a reason the scanner
cannot see, and runtimes on both sides of a published end-of-support date.
